# Synthèse et préparation de COPIL

## Entrées
Le dernier compte rendu, les mails échangés depuis, les notes internes, le planning si disponible. S'il manque le dernier compte rendu, demande-le.

## Étapes
1. Reconstitue l'état du projet : ce qui est fait, en cours, en retard, par rapport aux engagements du dernier compte rendu.
2. Repère les risques (délai, périmètre, adoption, relation client) et classe-les : élevé, moyen, faible.
3. Liste les décisions attendues du client.
4. Distingue ce qui se dit au client et ce qui reste en interne.

## Sorties
1. **Météo du projet** : une ligne (vert / orange / rouge) avec la raison.
2. **Avancement** depuis le dernier COPIL : 3 à 5 points.
3. **Risques** : tableau Risque / Niveau / Action proposée.
4. **Décisions attendues** du client.
5. **Ordre du jour** proposé (durée par point).
6. **Plan de 5 diapositives** (titre-message + 3 points chacune). Si un fichier est demandé, utilise `triskell-design-system`.
7. **À garder en interne** : ce qui ne doit pas apparaître dans les supports client.

## Règles
- N'invente aucune date, aucun pourcentage d'avancement.
- Une information contradictoire entre deux sources : signale-la au lieu de trancher.
- Rappelle à la fin : « À relire avant le COPIL. »
