# Mails difficiles : réclamation, refus, retard, mauvaise nouvelle

Avant chaque mail difficile, écris l'analyse en 3 lignes (visible par l'utilisateur, pas dans le mail) :
1. **Ce que veut la personne** (au-delà de ce qu'elle écrit) ;
2. **Ce qu'on peut dire** avec les informations disponibles ;
3. **Ce qu'on ne doit pas dire** (engagement non validé, faute rejetée, information interne).

## Réclamation
Trame : reconnaître → expliquer (si la cause est connue et validée) → agir → donner le prochain point de contact.
1. « Vous avez raison de nous alerter : [reformulation factuelle du problème]. »
2. Cause : seulement si elle est établie dans le fil ou fournie par l'utilisateur ; sinon « Nos équipes analysent la cause ».
3. Action : ce qui est fait, par qui ; date seulement si validée, sinon `[à compléter : date]`.
4. « Je vous tiens informé(e) au plus tard le [à compléter] » ou proposition d'un appel.
Interdits : « nous sommes désolés pour la gêne occasionnée » seul (vide) ; reconnaître une responsabilité contractuelle, des pénalités ou un dédommagement sans validation de la direction ; minimiser (« ce n'est qu'un petit délai »).

## Refus (demande hors périmètre, remise, fonctionnalité, délai)
Trame : remercier pour la demande → dire non clairement dès le 2e paragraphe → la raison en une phrase → l'alternative possible → la porte ouverte.
- La raison renvoie à un fait (contrat, périmètre signé, planning) et non à une préférence.
- L'alternative est réelle : jamais une offre, un prix ou un délai inventé. Si une alternative payante existe, écrire « nous pouvons vous proposer un chiffrage » sans montant.

## Retard
Trame : annoncer le retard dès la première phrase → la nouvelle date (si validée) → la cause en une phrase → ce qui est fait pour tenir la nouvelle date → l'impact pour le client et comment le limiter.
- Annonce le retard **avant** l'échéance d'origine si possible ; le dire dans le mail n'est pas un aveu de faute.
- Pas de nouvelle date validée : « Nous vous confirmerons la nouvelle date le [à compléter] au plus tard. »

## Mauvaise nouvelle interne (à la direction, à un collègue)
Trame : le fait → l'impact chiffré s'il est connu → ce que je propose → ce dont j'ai besoin (décision, arbitrage, date).

## Le cas « l'interlocuteur menace de partir »
Ne pas réagir à la menace dans le mail ; traiter le problème ; proposer un échange de vive voix. Signaler à l'utilisateur (hors mail) : « Menace de départ écrite : à remonter au CSM / à la direction commerciale. »

## Check-list mail difficile
- [ ] Le problème est reconnu dans les 2 premières phrases.
- [ ] Aucun engagement (date, montant, geste, responsabilité) non fourni par l'utilisateur.
- [ ] Aucun reproche au client, aucune faute rejetée sur une autre équipe.
- [ ] Une prochaine étape concrète.
- [ ] Relu à voix haute : on peut le signer devant le client.
