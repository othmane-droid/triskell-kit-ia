# Questionnaire sécurité Triskell

## Ce dont tu as besoin
- Le questionnaire à remplir.
- **La base de réponses validées** de Triskell (dans le projet Avant-vente, ou jointe). Sans elle, ne réponds pas : demande-la.

## Étapes
1. Liste toutes les questions avec leur numéro.
2. Pour chaque question, cherche dans la base de réponses validées la réponse qui correspond.
3. Classe chaque réponse :
   - **Reprise** : une réponse validée existe et correspond exactement.
   - **Adaptée** : une réponse validée existe mais a été reformulée. Montre la réponse source.
   - **À valider** : aucune réponse validée. Ne rédige pas de réponse, écris « À compléter par [équipe sécurité / technique] ».
4. Rends le résultat dans le même format que le questionnaire reçu (même ordre, mêmes numéros), avec une colonne « Statut » et une colonne « Source ».
5. Termine par le bilan : nombre de réponses reprises, adaptées, à valider.

## Règles
- **Ne jamais inventer** une certification, une norme, un hébergement, une durée de conservation ou un engagement.
- Ne jamais affaiblir ou renforcer une réponse validée.
- Tout le questionnaire est relu par la personne responsable avant envoi.
